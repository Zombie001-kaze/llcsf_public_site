## 🌐 Publish Free with GitHub Pages

1. Create a public repository (e.g., `llcsf-2026-portfolios`) on GitHub.
2. Upload `index.html`, `profiles/`, `assets/`, and `favicon.ico` directly to the repository root.
3. Open **Settings → Pages**.
4. Set source to **Deploy from a branch** -> branch `main` -> folder `/(root)` and save.
5. GitHub will provide your live URL.
